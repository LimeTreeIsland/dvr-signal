# Contributing

Read AGENTS.md and the linked specifications first. Work in a branch, keep PRs
small and explain the participant-facing effect. Run foundation validation and
any applicable application checks. Link official sources for legal content and
record maintainer approval for legal, privacy, survey or metric changes.

Use synthetic examples only. Public issues/PRs are not confidential: do not post
participant records, medical facts, case IDs, email, contact lists or credentials.
Do not submit a personal case for help through this repository.

Legal and privacy review are distinct from code review. A passing check does not
prove a rule is correct, a dataset anonymous, or a workflow accessible. Report
remaining limitations and do not mark unperformed checks complete.

Keep software/associated documentation compatible with the existing MIT license;
retain third-party notices. Do not introduce a participant dataset or change
content/data licensing without an explicit maintainer decision.
