# Project specification

Version: 0.1.0 · Prepared: 2026-09-26 (America/Los_Angeles)

## Mission and status

DVR Signal is independent, evidence-forward, participant-centered, nonpartisan,
and factual. It compares an accurately sourced Washington DVR process with actual
reported experiences. It helps people ask useful questions and prepare requests.
It does not promise services, legal outcomes, representation, or systemic findings
before evidence exists.

The supplied project brief and visible planning establish the scope below.
New implementation details in this foundation are proposals, not previously
approved legal interpretations. This package does not activate a survey or tool.

## Phase 1 deliverables

| Area | Deliverable | Acceptance |
| --- | --- | --- |
| Help | Five tools sharing one engine | Local form → applicable information → editable request → copy/print/save |
| Explain | Healthy-process guide | Sources, timeframes where supported, conditions and non-linear paths |
| Listen | Separate anonymous survey | 3–5 minute usability target; approved dictionary and privacy notice |
| Measure | Aggregate dashboard | Explicit denominators, suppression, revision date and sample caveat |
| Trust | Methods, sources, privacy, accessibility pages | Evidence classes and limitations visible |

Five tools: Pathway Navigator; Get My DVR Records (Records Router);
Accommodation Builder; Written Decision + Deadline Checker; Challenge a DVR
Decision. Records Router is the first complete implementation slice.

Out of scope: individual legal representation, automated agency submissions,
document uploads, public raw records, participant accounts, staff rankings,
automated findings of unlawful conduct, and a custom backend.

## Governance

LimeTreeIsland owns product decisions and approval of legal interpretations,
privacy changes, metric denominators, public data release, and survey meaning.
Record each material change with reason, evidence, impact, approval reference,
version, and migration/backfill consequences. A code merge alone must not silently
reclassify historic cases or metrics.

Preserve user effort: small issues, working previews, clear acceptance criteria,
and a short list of decisions requiring judgment. Do not repeatedly ask for
approval of ordinary reversible implementation within authorized scope.
