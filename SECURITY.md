# Security and privacy reports

This public repository is for software and methodology, not confidential case
intake. Never post secrets, private survey rows or participant records in issues,
PRs, commits, screenshots, or workflow logs.

If GitHub's private vulnerability reporting is enabled, use the repository's
Security → Advisories → Report a vulnerability route. This foundation has not
enabled or verified that setting. If unavailable, open only a minimal issue asking
the maintainer to establish a private reporting channel; include no exploit
details, credentials, identifiers or participant information.

Do not upload evidence until a private channel and access policy are confirmed.
No response-time guarantee or dedicated private email is established yet.

Maintainer response: limit ongoing exposure, revoke exposed credentials, preserve
necessary incident evidence privately, assess affected data and copies, remediate,
and document actions without republishing sensitive material. Deleting a file
does not erase its git history, forks or caches.
